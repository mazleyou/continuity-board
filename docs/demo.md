# 2분 데모 대본

**메시지:** “같은 캐릭터를 생성한다”가 아니라 **“캐릭터 기준을 지키면서 고칠 수 있고, 그 과정을 누구나 실행할 수 있다.”**

## 준비

- 데모 프로젝트에 캐릭터 기준 v1을 승인하고 6컷 장면을 입력해 둡니다. Mac Studio M5 Ultra에서는 컷 1장이 약 10초라 현장에서 생성해도 됩니다. 메모리가 작은 장비라면 미리 생성해 두세요.
- 일부러 틀린 컷 하나를 남겨 둡니다(예: 4컷의 가방 색이 다름).
- 실제 모델 없이 리허설할 때는 `npm run start:mock`을 씁니다.

## 진행

| 시간 | 화면 | 말할 내용 |
|---|---|---|
| 0–20초 | 왼쪽 **캐릭터 기준**(얼굴·전신 참조, 특징 v1)과 6컷 보드 | “캐릭터 기준은 버전으로 저장되고, 모든 컷은 승인된 원본 참조에서 생성됩니다. 직전 컷을 이어 붙이지 않습니다.” |
| 20–60초 | 컷을 열어 후보 **나란히 비교** → 승인 도장 | “후보는 몇 개를 만들어도 승인본을 덮어쓰지 않습니다. 승인은 사람이 합니다.” |
| 60–100초 | 4컷 → **영역 칠하기**로 가방만 칠하고 `Change her bag to the small red shoulder bag` → 진행률 막대 → 새 후보 → **겹쳐 밀기** 비교(칠한 곳만 바뀜) → 승인 → 마음에 안 들면 이전 후보로 **복원** | “수정은 새 후보로만 추가됩니다. 칠한 영역 밖은 원본과 픽셀 단위로 같고, 어떤 참조와 지시로 고쳤는지 이력으로 남습니다.” |
| 100–120초 | **무결성 확인** 토스트(다른 승인 컷 해시 동일) → **내보내기 ZIP**(보드 PNG, 컷, 프로젝트·워크플로 JSON) → ZIP을 ComfyUI에 끌어 놓아 워크플로 열기 | “승인 컷의 파일 고정은 시스템이 보장합니다. 캐릭터 특징은 모델로 유도할 뿐 완전히 보장하지는 않습니다. 이 흐름 전체가 오픈소스이고, ComfyUI에서 그대로 열어 고칠 수 있습니다.” |

## 피할 표현

- “캐릭터가 100% 유지됩니다.” → 특징 유지는 **유도**입니다.
- “다른 도구에는 없는 기능입니다.” → 이 흐름을 **누구나 실행하고 고칠 수 있는 오픈소스 구현**이라고 설명합니다.
